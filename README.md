# DesignThings

A lightweight browser-based visual planning tool. Draw rectangles, arrange them on a canvas, snap edges and centers into alignment, and attach notes to keep track of what each shape represents.

## Features
- Rectangle and note tools
- Drag, resize, select, and delete objects
- Smart alignment snapping while moving shapes
- Edit dimensions and canvas positions precisely
- Choose colors and canvas backgrounds
- Undo / redo
- Automatic local saving in your browser
- Export your canvas as SVG
- Responsive layout and keyboard shortcuts

## Run
Open `index.html` in a modern browser. No build tools, dependencies, or server required.

## Shortcuts
- `V`: Select
- `R`: Rectangle
- `N`: Note
- `Delete`: Delete selected object
- `Ctrl/Cmd + Z`: Undo
- `Ctrl/Cmd + Y`: Redo
